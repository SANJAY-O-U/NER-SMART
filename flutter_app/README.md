# NER-SMART Driver App (Flutter)

Minimal driver-side app for the SIH26002 golden demo. Talks directly to the
EXISTING Node/Express backend — no separate backend.

## Why you need to run `flutter create` first

This folder has the Dart application code (`lib/`) and `pubspec.yaml`, but
NOT the native Android/iOS/etc. project scaffolding (`android/`, `ios/`,
`build.gradle`, `Info.plist`, ...). That scaffolding must be generated by
your local Flutter SDK — hand-written native project files are fragile and
version-dependent, so let `flutter create` do it correctly.

## Setup (5 minutes)

```bash
cd flutter_app
flutter create .          # generates android/ ios/ etc. IN PLACE, keeps lib/ and pubspec.yaml
flutter pub get
```

## Required permissions

**Android** — add to `android/app/src/main/AndroidManifest.xml`, inside `<manifest>` (before `<application>`):
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

**iOS** — add to `ios/Runner/Info.plist`, inside the top-level `<dict>`:
```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>NER-SMART needs your location to attach it to an incident report.</string>
```

If you skip these, location capture will fail and the app will automatically
fall back to the fixed demo coordinate (see below) — the report flow will
still work end-to-end, just without live GPS.

## Point it at your backend

The backend URL is passed at build time (see `lib/config/app_config.dart`):
- Android emulator: `flutter run` — defaults to `http://10.0.2.2:5000/api` in debug.
- iOS simulator: `flutter run --dart-define=NER_API_BASE_URL=http://127.0.0.1:5000/api`.
- Physical device: `flutter run --dart-define=NER_API_BASE_URL=http://192.168.1.42:5000/api`
  (use your machine's LAN IP; same network; allow the port through your firewall).
- Release: `flutter build apk --release --dart-define=NER_API_BASE_URL=https://<host>/api`
  — HTTPS is mandatory; a release build without it shows a configuration error.

## Run

```bash
flutter run
```

## Demo reliability

If GPS is unavailable (emulator, denied permission, no fix), the app uses a
fixed fallback coordinate that sits on the NH-2 Guwahati-Imphal Highway
point already seeded in the backend — so the incident still associates with
a real road on the map even without live location. This is clearly labelled
in the UI ("demo location — live GPS unavailable"), per the project's
technical-honesty requirement.

## Flow

HOME → REPORT INCIDENT (category + description + location) → PROCESSING
(submits to `POST /api/incidents`, which runs the backend's AI pipeline) →
RESULT (incident ID, AI classification, severity, confidence, associated
road, status).
